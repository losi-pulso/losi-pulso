LOSI PULSO 3.1 — PLAYER PARA TELA BLOQUEADA + MP3 LONGOS (PREPARAÇÃO)
====================================================================

A) ATUALIZAR O APP QUE VOCÊ JÁ USA NO IPHONE
1. Abra https://github.com/losi-pulso/losi-pulso
2. Clique em Code > Add file > Upload files.
3. Extraia o ZIP e envie TODOS os arquivos web soltos (incluindo index.html,
   background-player.js, background-player.css, sw.js, mp3.js, app.js, etc.).
   NÃO envie a pasta como uma subpasta; os arquivos devem ficar na raiz.
4. Confirme em Commit changes e espere o GitHub Pages publicar.
5. Abra https://losi-pulso.github.io/losi-pulso/ no Safari do iPhone.
6. Feche e reabra o atalho Losi Pulso na tela inicial. Se o app não atualizar,
   abra pelo Safari primeiro; NÃO apague dados do site pois pode perder downloads.

B) TESTAR A MÚSICA COM A TELA BLOQUEADA
1. Em Sets > MP3 escolha uma faixa aprovada e toque em Ouvir.
2. Se o iPhone impedir autoplay após a busca do arquivo, toque em ▶ na nova
   barra verde fixa na parte inferior do app. Isso é uma regra do navegador.
3. Comece a tocar um MP3, pressione o botão de bloquear e teste no iPhone.
4. Tente controlar play/pausa e avanço pela tela de bloqueio/Central de Controle.
5. Repita com um MP3 baixado em Sets > Offline, ou um MP3 importado em Biblioteca.

IMPORTANTE: Um PWA pelo Safari NÃO pode habilitar AVAudioSession/Background Modes
como um app iOS nativo. Funciona por HTMLAudioElement e Media Session quando
suportado, mas NÃO garantimos reprodução contínua em TODOS os iPhones/iOS.
Loops de demonstração sintetizados em WebAudio podem parar com a tela bloqueada.
A versão nativa com áudio em background é a solução definitiva.

C) ARQUIVOS MP3 GRANDES
- Atualmente, o projeto Supabase guarda MP3 no bucket privado 'lp-mp3'.
- Limite real do backend hoje: 50 MB por MP3. A interface continua respeitando
  esse limite para NÃO prometer uploads que o servidor recusará.
- O código de envio utiliza TUS resumable (chunks de 6 MB): ele já admite
  redes instáveis e continuará funcionando se o limite do backend for ampliado.
- Para MP3 acima de 50 MB, duas opções:
  1) Supabase Pro: ajuste Global File Size Limit em Storage > Settings,
     execute o SQL opcional BACKEND/03_APOS_UPGRADE_SUPABASE_PRO.sql e altere
     config.js > maxMp3UploadMB: 500. ISSO PODE GERAR COBRANÇA.
  2) Cloudflare R2 Standard + Worker privado: permite uploads maiores e tem
     franquia gratuita sujeita a limites. É preciso configurar nova conta,
     bucket, Worker para autorização e download e integrar na tabela de mídia.
     R2 AINDA NÃO FOI CONFIGURADO NESTE PACOTE.
- Os uploads NÃO continuam em segundo plano se o iPhone encerrar o PWA.
- Os downloads offline também dependem da cota local do Safari/iOS.

D) APROVAÇÃO E DIREITOS AUTORAIS
Todo MP3 enviado mantém status 'pending' até o administrador aprovar.
O app não deve redistribuir obras sem permissão de seus titulares.
Arquivos aprovados ficam disponíveis para reprodução e download offline
conforme as permissões da plataforma.

E) VALIDAÇÃO
A sintaxe JavaScript e as rotas de navegação foram verificadas em testes locais.
Não foi possível realizar um teste de execução em Safari iOS real aqui.
O novo player e o envio de MP3 >50 MB precisam ser testados no ambiente alvo.
