LOSI PULSO V3 — VÍDEOS + MÚSICAS MP3 + DOWNLOAD OFFLINE
=======================================================

ENDEREÇOS QUE JÁ SÃO SEUS
Repositório GitHub: https://github.com/losi-pulso/losi-pulso
Aplicativo iPhone: https://losi-pulso.github.io/losi-pulso/

ATUALIZAR SEM EXPO GO, NETLIFY OU NOVA CONTA
1. No Windows, baixe e EXTRAIA o ZIP "Losi_Pulso_v3_Atualizar_GitHub.zip".
2. Abra https://github.com/losi-pulso/losi-pulso
3. Vá em Code > Add file > Upload files.
4. Selecione TODOS os arquivos extraídos DENTRO DA PASTA, não a pasta nem o ZIP.
   IMPORTANTE: index.html, app.js, sets.js, mp3.js, offline.js, offline.css,
   styles.css, sets.css, config.js, sw.js, audio-engine.js, manifest.webmanifest
   e os ícones devem ficar diretamente na raiz do repositório.
5. Finalize em Commit changes. Os arquivos existentes serão atualizados.
6. Settings > Pages já deve estar configurado em main / (root). Não mude.
7. Aguarde alguns minutos. Abra o endereço do aplicativo no Safari do iPhone.
8. Feche e abra de novo o aplicativo instalado para carregar a versão nova.
   Se houver cache antigo, atualize a página no Safari e volte a abrir o app.
   NUNCA limpe os dados do Safari se quiser manter downloads offline.

COMO O USUÁRIO BAIXA
- No app, acesse Sets > Vídeos e toque em "Baixar vídeo offline" num set aprovado.
- Em Sets > MP3, toque em "Baixar offline" numa faixa aprovada.
- Abra Sets > Offline, ou Biblioteca > Downloads offline.
- Toque em Reproduzir mesmo com modo avião.
- Exclua os arquivos por meio do botão × da biblioteca offline.
- MP3 IMPORTADO PELO PRÓPRIO USUÁRIO: Biblioteca > Adicionar; estes arquivos
  já ficam localmente armazenados na biblioteca pessoal anterior.

COMO O DJ PUBLICA MP3
- Sets > + Enviar vídeo (para entrar ou criar conta, se necessário).
- Sets > MP3 > + Publicar. O MP3 ficará pendente.
- Conta administradora: Sets > MP3 > Aprovar para liberar reprodução/download.
- A conta admin deve constar na tabela public.admin_users do Supabase.

LIMITES E CUIDADOS
- Esta v3 limita downloads, uploads de vídeo e de MP3 a 50 MB por arquivo.
- Supabase guarda os vídeos e MP3 na nuvem; GitHub Pages hospeda apenas o app.
- Downloads offline ficam no IndexedDB da instalação PWA, NÃO na pasta Arquivos.
- O iOS pode apagar dados para economizar armazenamento: NÃO são backups permanentes.
- O download OFFLINE exige internet inicialmente; a reprodução depois não exige.
- Vídeos externos incorporados do YouTube NÃO estão disponíveis para download.
- Downloads de terceiros exigem autorização dos respectivos titulares de direitos.
- Se a publicação estiver aberta a todos, inclua termos de uso, antispam,
  denúncias de conteúdo e uma política de direitos autorais antes de produção.

BACKEND PRONTO
Foi executada uma migração de MP3 no seu projeto Supabase "Pulso Losi".
Bucket privado lp-mp3 e tabela lp_mp3_tracks já configurados.
NÃO execute os SQLs novamente no projeto atual.
Verifique Authentication > URL Configuration > Redirect URLs:
  https://losi-pulso.github.io/losi-pulso/

COMO TESTAR NO IPHONE
1. Entre em uma conta DJ e envie um MP3 pequeno do qual você tem direitos.
2. Entre como administrador e aprove o MP3.
3. No catálogo MP3, toque em Baixar offline.
4. Abra Offline, ligue o MODO AVIÃO e toque em ▶ na faixa baixada.
5. Repita com um vídeo MP4 curto aprovado.
6. Reabra o app offline para verificar se a biblioteca persiste.

AVISO: a estrutura e a sintaxe foram validadas, mas o teste real de login,
upload e modo avião no seu iPhone ainda depende de você executar os passos.
